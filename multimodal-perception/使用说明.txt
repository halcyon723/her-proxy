多模态感知实现 · 源码包
========================

一、这是什么
本压缩包是你本机「独居女性照料 · 多模态感知交互系统」的运行源码：
摄像头姿态识别(视觉) + 豆包语音识别 + 火山方舟对话(LLM) + 语音播报(TTS)。

包含 10 个文件，全部解压到同一个文件夹即可。

二、安装依赖（Python 3.10）
    pip install -r requirements.txt

三、填回 API Key（重要）
出于安全考虑，压缩包内的 config.py 已把 API Key 清空，你需要填回自己的密钥：

1. LLM_API_KEY（火山方舟对话大模型）：
   控制台 https://console.volcengine.com/ark  → API Key 管理
2. ASR_API_KEY（豆包语音识别，与方舟 key 不是同一个）：
   控制台 https://console.volcengine.com/speech/new/setting/apikeys
3. TTS_VOLCANO_API_KEY（可选，语音合成，留空则用 edge-tts 免费女声）

填入后保存 config.py 即可。

四、运行
    python main.py
- 摄像头设备号如需更换，改 config 旁的 main.py 顶部 CAMERA_INDEX = 0
- 首次运行会自动生成 command.json（动作指令）、period_remind_state.json（经期剧情状态）
- 想重新演示经期剧情：删除 period_remind_state.json 后重启

五、按键
A 模拟捂肚子触发经期剧情 / T 拿纸巾指令 / W 拿水杯指令 / Q 退出

六、安全提示
config.py 含你的 API Key，请勿把填好密钥的版本发给他人。
